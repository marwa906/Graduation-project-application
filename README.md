# CG.OI - Career Support Platform

A smart full-stack application designed for students and graduates to discover career paths, improve CVs, and prepare for interviews.

## 📋 Overview

CG.OI is a comprehensive career support platform that empowers users to:
- Choose the right career path
- Improve their CV and cover letters
- Prepare for job interviews
- Discover job and internship opportunities

## 🏗️ Architecture

**Frontend:**
- Flutter Mobile App
- Modern UI/UX Design
- Real-time data sync

**Backend:**
- Node.js / Express.js
- RESTful APIs
- Career matching algorithms
- CV analysis engine

**Cloud & Database:**
- Firebase / Firestore
- Authentication & Authorization
- Cloud Storage

## ✨ Features

- User Authentication & Profile Management
- Career Assessment & Path Recommendations
- CV Upload & AI Analysis
- Interview Preparation Resources
- Job Board & Internship Listings
- Real-time Notifications
- Advanced Search & Filtering

## 🛠️ Tech Stack

| Layer | Technology |
|-------|-----------|
| Frontend | Flutter, Dart |
| Backend | Node.js, Express.js |
| Database | Firebase, Firestore |
| Authentication | Firebase Auth |
| Cloud Functions | Firebase Cloud Functions |
